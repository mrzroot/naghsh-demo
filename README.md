# نقش کاغذ | Naghsh concepts

دو نمونهٔ مستقل برای بررسی تجربهٔ فروشگاه نوشت‌افزار و خدمات چاپ. داده‌ها نمونه‌اند؛ این مخزن فروشگاه عملیاتی نیست.

| طرح | ویژگی اصلی |
| --- | --- |
| [بوتیک](kaghazineh.html) | ویترین گرم با قاب طاق، کاغذ ابری، کاتالوگ و مسیر خدمات چاپ |
| [استودیو](naghsh-studio.html) | ویترین مدرن با صحنه‌های متحرک، جست‌وجوی سریع و برآورد خدمات |

## اجرا و بازبینی

از ریشهٔ مخزن `python -m http.server --bind 127.0.0.1 8000` را اجرا و `http://127.0.0.1:8000/` را باز کنید. [صفحهٔ آغاز](index.html) به هر دو طرح پیوند دارد. ابزار ساخت لازم نیست؛ فونت‌های آنلاین در صورت نبود اتصال با فونت جایگزین نمایش داده می‌شوند.

برای بازبینی، در هر دو طرح مسیر پیدا کردن محصول، برآورد چاپ، تغییر زبان و نمایش موبایل را مقایسه کنید.
